## Key takeaways

- Exploratory Data Analysis (EDA) is a foundational approach that should precede confirmatory data analysis
- EDA involves examining data visually to identify patterns, outliers, and relationships before formal statistical testing
- Visual representations of data are crucial for understanding distributions and identifying anomalies
- The "jackknife" approach can be used to handle outliers by removing them and checking if the dataset remains representative
- Assignment 4 focuses on exploring a single variable through EDA techniques
- Excel tools like descriptive statistics, histograms, and pivot tables are useful for conducting EDA
