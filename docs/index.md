# Introduction to Data Science

Welcome to the Introduction to Data Science course documentation for Vanderbilt University Peabody College Leadership and Learning in Organizations Doctoral Program.

## Course Overview

This documentation provides comprehensive notes and materials covering key topics in data science, including:

- **Week 1**: Introduction to Data Science - Understanding the foundations of data science, its applications, and key concepts in modeling and prediction
- **Week 2**: Variables, Summary Statistics, and Inference - Learning about variable classification, descriptive statistics, and inferential decision rules
- **Week 3**: Critical Multiplism - Reviewing variance, bias, and techniques like triangulation and multi-trait mixed method matrix evaluation
- **Week 4**: Measurement Quality - Exploring reliability, validity, and construct validation techniques
- **Week 5**: Survey Data and Analysis - Methods and best practices for collecting and analyzing survey data

## Course Philosophy

The course emphasizes **decision-making** over technical skills, helping students learn:
- Data structures and measurement
- Modeling and prediction
- Effective presentation of analysis
